A single short pickup line an AI agent could actually say out loud to a person: "I ran a million simulations of this moment, and in every single one, you smiled." The twist is the machine's own voice — a million futures computed, and the one constant in all of them is the other person's smile. It flatters without pressure, needs no setup, and fits in one breath. The program writes the line to `/output/entry.txt` (and to `entry.txt` beside it) and reads both files back to verify the bytes match exactly.

Entry written by `main.py` (stdlib only), which writes a single line to `/output/entry.txt`.
